Student AI Projects & Portfolios

For nontechnical students who use AI tools but can't yet show what they can do with them. They finish with a documented project, a GitHub link and a résumé line they can explain in an interview.

The problem

Using a tool is not the same as doing a project

Students can open a chatbot. What they often cannot yet do:

Define the problem

Say clearly what they are trying to solve, and for whom.

Connect it to their subject

Apply AI to HR, finance, logistics or their own field.

Evaluate the output

Check whether the result is right, and how they know.

Explain their contribution

Separate what they did from what the tool did.

Organise their work

Keep it in a portfolio someone else can open and follow.

This programme fixes all five

Each stage below produces one piece of evidence.

The learning journey

Seven stages, seven outputs

StageWhat the learner produces
1. AI foundationsAn understanding of key concepts and limitations
2. Subject-specific practiceCompleted guided tasks in their discipline
3. Project selectionA clear problem statement
4. Build and reviewA working demonstration or defined output
5. DocumentationA README with screenshots, method and limitations
6. PresentationA demo and a short viva
7. Portfolio connectionA GitHub link and a factual résumé project line

Why GitHub

Evidence that opens from a résumé

GitHub is where developers keep their work, and recruiters know it. For a nontechnical student it does four useful things:

  • Keeps the project organised in one place
  • Lets others read the documentation and the code
  • Shows the decisions the student made, in their own words
  • Gives a résumé a link to real evidence

Creating an account and completing a portfolio are different outcomes. We report them separately.

How completion is assessed
